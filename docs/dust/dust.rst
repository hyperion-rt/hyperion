Library of dust models
======================

While you are encouraged to prepare your own dust properties file based on the
most appropriate dust model for your problem (see :doc:`../setup/setup_dust`),
we provide a library of dust models that you can select from. These are
available in the `hyperion-dust`_ package, which can be installed with::

    pip install hyperion-dust

Since dust files tend to be large, the package only includes the tabulated
optical properties, and builds the dust objects and files when they are
requested. To get a dust object that can be used directly in a model, use
``get_dust`` with the name of one of the dust models listed below::

    from hyperion_dust import get_dust

    dust = get_dust('kmh94_3.1_full')

    m.add_density_grid(density, dust)

Dust sublimation can be included by giving the sublimation mode and
temperature (see :ref:`dust_sublimation`)::

    dust = get_dust('kmh94_3.1_full', sublimation_mode='fast',
                    sublimation_temperature=1600)

If you need an HDF5 dust file instead, ``get_dust_filename`` takes the same
arguments and returns the path to the file::

    from hyperion_dust import get_dust_filename

    m.add_density_grid(density, get_dust_filename('kmh94_3.1_full'))

The file is generated the first time it is requested and is then re-used. The
files are kept separately for each version of Hyperion, so they do not need to
be re-generated by hand if the format of the dust files changes.

 .. admonition:: Disclaimer

    The choice of which dust model to use is entirely yours, and you should
    make sure that the dust model that you pick is appropriate for the
    scientific problem you are trying to solve. In addition, as for the
    radiative transfer code itself, we cannot guarantee that the dust files are
    bug-free - you should sign up to the `mailing list
    <https://groups.google.com/forum/?fromgroups#!forum/hyperion-announce>`_ to
    ensure that you are informed as soon as bugs are identified and fixed.
